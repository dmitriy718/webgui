# Papers

The two theory papers behind Aegis Memory. Both are preprints — arXiv
submission is pending (the author submits from his own account).

- **`gyromem-paper.tex`** — *GyroMem: Curvature-Adaptive Memory for
  Long-Horizon LLM Agents*. Memories on a mixed-curvature manifold;
  geodesic retrieval, reconsolidation, and forgetting. **The .tex is
  authoritative.** `gyromem-paper.pdf` is included for convenience but is
  stale (pre-dates the Nov 3, 2026 revision round).
- **`five-postulates-paper.md`** — *Five Postulates for Persistent
  Agentic Memory* (Mnemodynamics). Rent, Inference, Reconsolidation,
  Relaxation, Authority Non-Creation, plus the epistemic immune system
  and the measured-deletion operation.

Both papers are theory with pre-registered experiments and kill criteria.
They make no empirical claims. The code in this repo implements the
mechanisms and ships five runnable scenarios (`npm run scenarios`) that
demonstrate them — the scenarios are the demonstration, not the papers'
Phase 2 evaluations.
